# 🔧 KB68 Assembly Guide

> To be filled during Weekend 6 (Build Day).

## Assembly Order
1. Solder SMD components (MCU, regulator, ESD, passives)
2. Power-on test (check 3.3V rail)
3. Flash firmware (via USB-UART)
4. Solder diodes (check polarity)
5. Test matrix (bridge pads with tweezers)
6. Install switches (through plate into PCB)
7. Install stabilizers
8. Assemble case (foam → PCB → mount → close)
9. Attach keycaps
10. Full test
