What makes it different

Engineered from scratch

No kits. No pre-made PCBs. Every trace, every line of firmware, every curve of the case — designed in-house.

⚡

QMK + VIA firmware

Open-source firmware with real-time key remapping. 4 programmable layers. N-key rollover. No software install needed — VIA runs in your browser.

🔌

USB-C with ESD protection

USB 2.0 Full Speed. USBLC6-2SC6 TVS diodes guard the data lines. Proper CC resistors for universal cable compatibility.

🧠

STM32 ARM Cortex-M3

72MHz processor with 64KB flash. 1ms polling rate. Enough power for RGB matrix effects, macros, and future wireless.

🇮🇳

Made in India

PCB fabricated in Gujarat. Case 3D printed locally. Components sourced from Indian suppliers. Built to prove that world-class R&D happens here.
